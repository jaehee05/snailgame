# 🐌 달팽이 레이싱

친구들끼리 **가상 코인**으로 즐기는 달팽이 경주 게임. Next.js + Firebase, Vercel 배포용.

- 90초마다 새 회차가 자동으로 시작 (베팅 45초 → 경주 34초 → 결과 11초)
- 매 회차 8마리 중 4마리가 추첨되어 출전
- 단승 / 연승 / 복승 / 쌍승 / 삼쌍승 5종 베팅, 배당은 몬테카를로로 자동 산출
- 로그인(Firebase Auth), 잔액·베팅·정산은 전부 서버에서 처리
- 관리자 페이지에서 게임 머니 지급 / 회수
- 커밋-리빌 방식으로 결과 조작 여부를 브라우저에서 직접 검증 가능

> 이 게임의 코인은 현금 가치가 없는 가상 코인입니다. 현금 환전이나 실제 도박 용도로 쓰라고
> 만든 게 아니며, 그런 기능은 들어 있지 않습니다.

## 어떻게 굴러가는가

회차 번호는 `floor(현재시각 / 90초)` 로 정해진다. 별도의 스케줄러나 크론이 없고, 서버·클라이언트
모두 시계만 보면 지금이 몇 회차의 어느 구간인지 알 수 있다.

회차마다 두 개의 시드가 있다.

| 시드 | 공개 시점 | 결정하는 것 |
| --- | --- | --- |
| `publicSeed` | 회차 시작과 동시에 | 출전표(어떤 달팽이가, 어떤 컨디션으로) → 배당 |
| `secretSeed` | 베팅 마감 직후 | 실제 경주 전개와 순위 |

베팅 중에는 `secretSeed` 대신 그 SHA-256 해시(커밋)만 공개된다. 마감 후 원본 시드가 공개되면
브라우저가 직접 해시를 다시 계산해 커밋과 대조한다 (`components/Fairness.tsx`). 결과를 나중에
바꿔치기하면 이 검증이 바로 깨지므로, 운영자도 결과를 손댈 수 없다.

경주 시뮬레이션(`lib/race.ts`)은 시드만 주어지면 완전히 결정론적이라, 서버와 모든 참가자의
화면에 같은 경주가 같은 순간에 재생된다.

배당은 `publicSeed` 로 만든 출전표를 900번 시뮬레이션해 적중 확률을 추정하고, 환급률(기본 90%)을
곱해서 만든다. 비공개 시드와는 무관하므로 배당표를 들여다봐도 결과를 알 수는 없다.

## 로컬 실행

```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev
```

## Firebase 설정

1. [Firebase 콘솔](https://console.firebase.google.com/) → 프로젝트 `snailgame-b08e2`
2. **Authentication → Sign-in method → 이메일/비밀번호** 사용 설정
3. **Firestore Database** 생성 (프로덕션 모드)
4. **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성** 으로 JSON 다운로드
   → `.env.local` 의 `FIREBASE_SERVICE_ACCOUNT` 에 통째로 붙여넣기 (base64 도 가능)
5. 보안 규칙을 `firestore.rules` 내용으로 교체

`firestore.rules` 는 클라이언트의 모든 읽기/쓰기를 막는다. 데이터는 서버의 Admin SDK 로만
드나들기 때문에, 브라우저 콘솔로 잔액을 고치는 건 불가능하다.

## Vercel 배포

```bash
npx vercel        # 최초 1회, 프로젝트 연결
npx vercel --prod
```

환경변수는 Vercel 프로젝트 설정 → Environment Variables 에 등록한다.

| 변수 | 필수 | 설명 |
| --- | --- | --- |
| `FIREBASE_SERVICE_ACCOUNT` | ✅ | 서비스 계정 JSON (또는 base64) |
| `ROUND_SECRET` | ⚠️ | 회차 시드 생성 키. `openssl rand -hex 32`. **노출되면 미래 회차 결과가 예측 가능해진다** |
| `ADMIN_EMAILS` | | 관리자로 자동 승격할 이메일(쉼표 구분) |

`NEXT_PUBLIC_FIREBASE_*` 는 코드에 기본값이 들어 있어서 따로 넣지 않아도 된다. (웹 설정값은
공개되어도 무방한 값이다.)

## 관리자

`ADMIN_EMAILS` 에 넣은 계정, 또는 **가장 먼저 가입한 계정**이 관리자가 된다.
관리자는 `/admin` 에서 참가자 목록·잔액을 보고 코인을 지급하거나 회수할 수 있으며,
모든 지급 내역은 `ledger` 컬렉션에 남는다.

## 구조

```
app/
  page.tsx            경주장 (메인)
  login/              로그인 · 회원가입
  admin/              관리자 (머니 지급)
  api/round           회차 정보 (출전표 · 배당 · 커밋/시드)
  api/me              내 상태 조회 + 밀린 회차 자동 정산
  api/bet             베팅 접수 (금액·배당 서버 검증)
  api/admin           참가자 목록 · 코인 지급
lib/
  config.ts           회차 타이밍과 각종 상수
  prng.ts             시드 기반 결정론적 난수
  race.ts             달팽이 로스터 · 경주 시뮬레이션
  bets.ts             베팅 종류 · 배당 산출 · 적중 판정
  seeds.ts            회차 시드와 커밋 해시 (서버 전용)
  round.ts            회차 계산 + 배당 캐시
  db.ts               Firestore 데이터 계층 (사용자 · 베팅 · 정산)
```

정산은 크론 없이, 사용자가 접속할 때 밀린 회차를 따라잡는 방식이다 (`settleUser`).
접속을 안 하고 있었더라도 다음에 들어오면 그동안의 회차가 순서대로 정산된다.
